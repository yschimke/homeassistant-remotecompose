# Wall fonts

The faces the `wall` bitmap-font filter (`WidgetHost.Wall`) draws a card's default-family text
in: the face a wall panel's player measures and draws with, so a card drawn from glyphs reads as
the panel would draw it from outlines. Server-only; the design sync doesn't serve them.

- `Roboto-Regular.ttf`, `Roboto-Bold.ttf`: Roboto v2.138 (Apache License 2.0), from
  googlefonts/roboto-2, the Android default face.
