# Third-party icon data in rc-converter

`rc-converter` bundles generated icon data from two upstream projects. Both are regenerated by
[`scripts/generate-mdi-icons.py`](../../scripts/generate-mdi-icons.py), which pins the versions
below.

## Material Design Icons

`src/main/kotlin/ee/schimke/ha/rc/icons/mdi/MdiPaths.kt` holds SVG path data for a subset of
[Material Design Icons](https://pictogrammers.com/library/mdi/) 7.4.47 (npm `@mdi/js` and
`@mdi/svg`), by the [Pictogrammers](https://pictogrammers.com/) icon group.

## Home Assistant icon tables

`src/main/kotlin/ee/schimke/ha/rc/icons/HaIconTables.kt` lists Home Assistant's default entity
icons, taken from [Home Assistant core](https://github.com/home-assistant/core) 2026.10.2
(`homeassistant/components/*/icons.json`) and the
[Home Assistant frontend](https://github.com/home-assistant/frontend) 20260930.4
(`src/data/icons.ts`). Both projects are licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). Copyright Home Assistant contributors.
