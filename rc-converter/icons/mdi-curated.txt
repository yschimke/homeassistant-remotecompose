# Material Design Icons bundled into rc-converter beyond the ones the generator collects itself.
#
# scripts/generate-mdi-icons.py always bundles:
#   * every `mdi:` name referenced by the bundled demo dashboards and preview fixtures,
#   * every icon in Home Assistant core's entity-component icon tables (domain and device-class
#     defaults, with their state and range variants),
#   * the frontend's domain fallbacks and state-icon special cases (sun, update, device_tracker,
#     input_datetime, battery levels).
#
# This list adds the icons Home Assistant users most often pick by hand, so a card's `icon:` on a
# real dashboard usually resolves too. One name per line, without the `mdi:` prefix; `#` comments.
# Keep it to icons people actually use: every entry ships in the APK (roughly 0.3 KB of path data each).
