# Agent notes

- **Cards must update on live data.** Every card converter takes one of
  two update paths — host-reproducible named bindings, or a
  `dataSignature` document re-encode. Read and follow
  [`docs/architecture/live-card-updates.md`](docs/architecture/live-card-updates.md)
  before adding or changing a `*CardConverter`. The default expectation:
  a new card keeps up with Home Assistant without going stale, and a
  screenshot test (one frozen frame) does **not** prove that — check each
  dynamic value against the contract.
- Do not exceed 1800px in any dimension when capturing or generating images (screenshots, previews, diffs). Downscale before returning or attaching them.
- Use `agent/...` for branch names, never `claude/...` or `copilot/...`
  (enforced by `.github/workflows/no-ai-coauthors.yml`).
- Strip agent `Co-authored-by` trailers and AI bot emails from commits and PR
  bodies before pushing, and never commit under an agent author/committer
  identity — an `@anthropic.com`/`@openai.com` email or an agent name like
  `Claude`. The `_Generated by [Claude Code]_` footer and agent-session links
  are fine — they don't claim authorship. A GitHub App bot *identity* like
  `claude[bot]` is exempt (bots land on branches by design); a
  `Co-authored-by: claude[bot]` **trailer** is not — a trailer is an
  authorship claim wherever it came from.
  Enforced in three places, all sharing one detector
  (`.github/scripts/agent-attribution-scan.sh`):
  - `.githooks/commit-msg` — blocks the commit as it is written.
  - `.githooks/pre-push` — scans every commit a push would add, on **any**
    branch. This is the one that catches commits the message hook never saw:
    amended, rebased, cherry-picked, or made before the hooks were installed.
  - `.github/workflows/no-ai-coauthors.yml` — the PR gate (which also scans the
    PR title and body, since the squash commit is built from them) plus a
    post-merge drift check on `main`.

  Install the hooks once per clone with `scripts/install-git-hooks.sh` (the
  `SessionStart` hook does it automatically in cloud sessions). `git commit
  --no-verify` / `git push --no-verify` bypass them locally — CI still won't.
  Change the detector only with `scripts/test-agent-attribution.sh` passing;
  CI runs it on every PR.
- Keep PR titles in conventional-commits form
  (`feat:`, `fix:`, `chore:`, `build:`, `ci:`, `docs:`, …); enforced
  by `.github/workflows/pr-title.yml` and consumed by release-please.
