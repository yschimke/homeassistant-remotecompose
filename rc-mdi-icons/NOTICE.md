# Third-party icon data in rc-mdi-icons

## Material Design Icons

`rc-mdi-icons` draws [Material Design Icons](https://pictogrammers.com/library/mdi/), by the
[Pictogrammers](https://pictogrammers.com/) icon group, from
[`io.github.timoptr:mdi-icons`](https://github.com/TimoPtr/mdi-icons) (Apache License 2.0), which
generates the whole catalog from the npm `@mdi/svg` release it pins (7.4.47 in 0.2.0).

The shared host UI also reuses the `lightbulb-on` and `lightbulb-outline` path data in
`app-ui/src/commonMain/kotlin/ee/schimke/terrazzo/shared/LightStateIcon.kt`. The same attribution
and licence apply to those two glyphs.
