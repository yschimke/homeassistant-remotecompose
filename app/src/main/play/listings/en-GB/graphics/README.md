# Play listing assets

The phone, tablet and (where supported) Wear screenshots are real ADB captures
of the running apps. See [capture instructions](../../../../../../../docs/play-screenshots.md)
and `docs/play-captures.json` for provenance. Regeneration from Compose previews
is intentionally disabled; weekly checks preserve these reviewed captures.

Icons and feature graphics remain branding artwork. Release listing publishing
uploads the checked-in images, so retain the image files and provenance together.
